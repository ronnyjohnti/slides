Fibers

  • Podem executar nosso código
  • Podem suspender a própria execução
  • Podem ser retomadas depois em outro lugar
  • Podem cuspir algum valor na suspensão
"Fibers são corrotinas de baixo nível para manipulação de concorrência no PHP."

Classe

                
                    final class Fiber {
                        public function __construct(callable $callback) {}
                        public function start(mixed ...$args): mixed {}
                        public function resume(mixed $value = null): mixed {}
                        public function throw(Throwable $exception): mixed {}
                        public function getReturn(): mixed {}
                        public function isStarted(): bool {}
                        public function isSuspended(): bool {}
                        public function isRunning(): bool {}
                        public function isTerminated(): bool {}
                        public static function suspend(mixed $value = null): mixed {}
                        public static function getCurrent(): ?Fiber {}
                    }

Exemplo de Fiber

                    
                        function inspire(string $name) {
                            echo "Essa Fiber é uma $name\n";
                            $resumeValue = Fiber::suspend($name);
                            echo "$name $resumeValue\n";

                            return $name;
                        }

                        $fiber1 = new Fiber(inspire(...));
                        $fiber2 = new Fiber(inspire(...));

                        $r1 = $fiber1->start('Rapadura');
                        $r2 = $fiber2->start('PHP');

                        echo "Fiber1 foi suspensa com $r1";
                        echo "Fiber2 foi suspensa com $r2";

                        $fiber2->resume('is not dead');
                        $fiber1->resume('is sweet but is not soft');

                        echo "Fiber1 retornou {$fiber1->getReturn()}";
                        echo "Fiber2 retornou {$fiber2->getReturn()}";
Essa Fiber é Rapadura Essa Fiber é PHP Fiber1 foi suspensa com Rapadura Fiber2 foi suspensa com PHP PHP is not dead Rapadura is sweet but is not soft Fiber1 retornou Rapadura Fiber2 retornou PHP

Fibers no Mundo Real

Imagine um servidor WebSockets em PHP:


                    $fiber = new Fiber(function() {
                        while (true) {
                            $msg = Fiber::suspend();
                            echo "Mensagem recebida: $msg\n";
                        }
                    });

                    $fiber->start();
                    $fiber->resume("Olá, mundo!");
                    $fiber->resume("Outra mensagem!");

Frameworks que já usam Fibers

  • ReactPHP - Suporte experimental
  • Amphp - Totalmente baseado em Fibers
  • Swoole - Usa Fibers para melhor performance

Conclusão

  • Fibers tornam a concorrência mais fácil e eficiente
  • Substituem padrões antigos como callbacks
  • O futuro da execução assíncrona no PHP é promissor!
